## Tools

| Key | Tool | Does |
| --- | --- | --- |
| <kbd>V</kbd> | Select | Select, move, resize; drag on empty map to box-select |
| <kbd>H</kbd> | Pan | Drag the view |
| <kbd>I</kbd> | Stamp | Place the stamp in hand |
| <kbd>B</kbd> | Blueprint | Place a saved group of objects |
| <kbd>G</kbd> | Scatter | Spray stamps (trees, rocks) |
| <kbd>L</kbd> | Line | Roads, rivers, borders, walls, fences |
| <kbd>C</kbd> | Ribbon | Curved strips: rail, roads with kerbs, conveyor belts |
| <kbd>O</kbd> | Area | Filled shapes: lakes, fields, forests |
| <kbd>F</kbd> | Floor | Paint squares with a texture |
| <kbd>X</kbd> | Erase floor | Unpaint squares |
| <kbd>R</kbd> | Room | A room with floor, walls and its own grid |
| <kbd>U</kbd> | Add/cut | Change a room's shape |
| <kbd>N</kbd> | Opening | Door, window or gap on the nearest wall |
| <kbd>T</kbd> | Text | Labels and notes |
| <kbd>P</kbd> | Pin | Pin a sub-location |
| <kbd>M</kbd> | Measure | Distance in the map's units |
| <kbd>E</kbd> | Erase | Delete what you click |

## Keys while editing

| Keys | Does |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Pan (<kbd>Shift</kbd>: faster) |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>V</kbd> / <kbd>D</kbd> | Copy, paste at the pointer, duplicate |
| <kbd>Delete</kbd> | Delete the selection |
| <kbd>[</kbd> <kbd>]</kbd> | Send back / bring forward |
| <kbd>Shift</kbd>+<kbd>H</kbd> / <kbd>Shift</kbd>+<kbd>V</kbd> | Flip left-right / top-bottom |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Join / separate rooms |
| <kbd>Q</kbd> <kbd>E</kbd> | Rotate the stamp or blueprint in hand (<kbd>Shift</kbd>: 90°) |
| <kbd>Z</kbd> <kbd>X</kbd> | Scale the stamp in hand; with a door selected, narrower / wider |
| <kbd>Alt</kbd> | Hold: no snapping, no joining |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |

## Right-click

With most tools, right-click opens a menu for the thing under the pointer or the selection: cut, copy, paste here, duplicate, add as blueprint, flip, rotate, join or separate rooms, order, delete. With the stamp, scatter or blueprint tool it goes back to Select.

## Panels

| Panel | Holds |
| --- | --- |
| Stamps | The stamp library, by group and style; paste or drop images to add your own |
| Blueprints | Saved groups of objects by category |
| Textures | Floor textures; **New from this** makes a derived texture (aged, tinted, extra detail) |
| Selected | Settings of the selected object |
| Layers | Layers, their order, hidden and locked |
| Pins | Sub-locations to pin, and how many levels down |
| Map | Size, grid, units, background, joining |
