## Everywhere

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>[</kbd> | Open or close the writer |
| <kbd>Ctrl</kbd>+<kbd>]</kbd> | Open or close the side drawer |
| <kbd>Escape</kbd> | Close the drawer |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the form or note you're editing |
| <kbd>/</kbd> | Search the docs (on a docs page) |
| <kbd>Ctrl</kbd>+<kbd>R</kbd>, <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd>, <kbd>F11</kbd> | Reload, zoom, full screen (desktop app) |

## Writer

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> | New paragraph / line break |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> | Bold / italic |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Link to a note: `[[ ]]` |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> / <kbd>H</kbd> | Strikethrough / highlight |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | Comment `%% %%` |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> | Scene break |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Indent / outdent a list item |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Move a block |
| <kbd>Escape</kbd> | Show the block formatted again |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find in the chapter |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Preview |

## Plan outlines

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> | Next event |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Sub event / back out |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Move an event |

## Blocks on notes

| Keys | Does |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move the block (in move mode) |
| <kbd>Enter</kbd> / <kbd>Escape</kbd> | Finish moving |

## World outline

| Keys | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> / <kbd>←</kbd> <kbd>→</kbd> | Select / fold |
| <kbd>A</kbd>, <kbd>M</kbd>, <kbd>F2</kbd> | Add inside, move, rename |
| <kbd>Enter</kbd> | Open the note |

The map editor's keys are in [Map editor tools and keys](docs:map-editor-reference).
